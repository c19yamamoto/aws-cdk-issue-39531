# AWS CDK issue 39531 reproduction

Minimal TypeScript CDK app for reproducing the IAM policy generated by `ec2.FlowLog` when sending VPC Flow Logs to CloudWatch Logs.

The app imports a placeholder VPC and lets CDK create the Flow Log, CloudWatch log group, IAM role, and IAM policy. No AWS account or deployment is needed to synthesize the template.

## Synthesize

```sh
npm ci
npm run synth
```

The synthesized CloudFormation template is checked in separately under [`cfn/`](./cfn/).
